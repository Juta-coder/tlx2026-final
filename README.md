## 🖥️ วันงาน · On the day (Facilitator)

1. เปิดลิงก์ **Big Screen** บนคอมที่ต่อโปรเจกเตอร์
2. ใส่ **Admin key** ที่แถบล่าง → กด **เข้า · Enter**
   (Admin key อยู่ที่ Apps Script → ⚙️ Project Settings → Script Properties → `ADMIN_KEY` · ห้ามใส่ไว้ในไฟล์นี้)
3. คุมเกมจากแถบล่าง

| ช่วง · Stage | จอใหญ่ทำอะไร | ผู้ดำเนินรายการกด |
|---|---|---|
| เข้าห้อง · Lobby | QR + รายชื่อที่เข้าแล้ว | รอทุกคนเข้า → **›** |
| คำถาม Q1–Q6 | Icon ทุกคนย้ายไปที่ Never / Sometimes / Frequently / Always | **›** ทีละข้อ |
| พร 3 ข้อ · 3 Wishes | ธีม Stardust Night | รอทุกคนขอพร → **จับคู่สุ่ม** → **›** |
| Commitment | จำนวนคนที่ส่ง (ไม่โชว์ข้อความ) | กดชื่อเพื่อ **แสดง** · **ซ่อน** · หรือ **ข้ามไปวงล้อ** |
| วงล้อ · Wheel | Wheel of Fortune | **หมุนวงล้อ** · คนที่ถูกสุ่มเห็น "ถึงตาคุณ 🎤" |
| ปิด · Close | ขอบคุณ + Export ลง Sheet อัตโนมัติ | — |

- **📱 QR เข้าเกม** (แถบล่าง ทุกช่วง) · สำหรับคนที่หลุดหรือมาสาย · มือถือเครื่องเดิม = กลับเข้าเป็นคนเดิม
- **Export ลง Sheet** · กดได้ทุกเมื่อ → แท็บ `Live_Results`
- **Reset** · ใช้หลังซ้อมเท่านั้น (ลบผู้เล่นและคำตอบทั้งหมด)
